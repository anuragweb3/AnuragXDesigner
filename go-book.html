Go Book Marketplace

Request Management System (RMS)

Project Scope

  • Designed a web-based Request Management System (RMS) focused on the Admin/Reviewer experience for handling and managing incoming requests.
  • Covered core workflows including request listing, detailed review screens, status management, and approval actions (Accept, Reject, Send Back).
  • Built data-heavy interfaces such as tables, filters, and dashboards optimized for quick scanning and efficient decision-making.
  • Designed structured read-only detail views for book and user information with clear visual hierarchy and actionable insights.
  • Established a scalable design system using grid layout, reusable components, and consistent spacing for desktop interfaces.

My Role

Owned the end-to-end UX design of the Admin panel, improving request handling through structured review screens and clear approval workflows.

Problem Statement

Books are essential, but access isn’t. Students struggle to afford academic books, readers often buy books they only read once, and selling old books is inconvenient and unstructured. Existing platforms either focus only on buying or lack trust in peer-to-peer transactions.
The Gap:There is no unified, trustworthy platform that supports-

  • Buying new/used books
  • Renting affordably
  • Selling easily

Goals

Design a unified book marketplace that allows users to-

  • Buy new & old books
  • Rent books easily
  • Sell books to vendors or other users

Target Users

• Students • Readers • Sellers
